# DownloadsCleaner · 下载目录空间清理

MoviePilot V3 插件：**磁盘可用空间低于阈值时，自动清理下载目录中已入库、做种超时的下载任务**。

## 功能特性

- **空间触发**：监控盘可用空间低于阈值（默认 300 GiB）开始清理，删到目标线（默认 350 GiB）即停
- **清理范围白名单**：仅清理「清理目录」指定子树内的任务（默认 `E:/Downloads`），天然排除 SSD / 保种专区
- **多重防护**（命中任意一条即跳过清理，**全部是保护性质**）：
  - **排除目录**：save_path 命中子树即跳过，**优先于清理目录**（清理目录内想保留的子目录填这里）
  - **保护标签**：默认 `保种`、`H&R`
  - **保护关键词**：路径或名称命中即跳过（如 `migration`）
  - **完成保护天数**（默认 7 天）：防止刚入库还在不稳定窗口期被删
  - 分享率门槛 / 小文件保护 / 要求已入库（整理记录或强制删除许可）
- **候选排序**：按做种时长从长到短清理，单轮数量可设上限
- **两阶段删除（可选）**：第一轮只打「待清理」标签，下一轮才真删，留出人工干预窗口
- **自动识别 MP 设置**：下载器（qBittorrent / Transmission）、通知渠道均从 MoviePilot 系统设置自动读取，无需填写地址密码
- **演练模式**：只记录不删除，先观察日志确认候选符合预期再切正式
- **同步清理 MP 记录**：删除任务同时清理整理记录与下载记录，避免幽灵记录
- **空目录回收（可选）**：删除后回收清理目录子树下的空目录
- **详情页**：累计/本轮删除统计、磁盘状态、当前候选清单、最近删除记录

> ### ⚠️ 名单语义速查（重要，避免配反）
>
> 本插件有四个名字带"名单"的配置，作用方向**不同**，配反了后果严重：
>
> | 配置 | 作用方向 | 命中后的效果 |
> |------|---------|-------------|
> | `clean_dirs`（清理目录） | **删除范围** | 只有目录子树内的任务才会被清理 |
> | `exclude_dirs`（排除目录） | **保护** | 跳过清理（优先于清理目录） |
> | `protect_tags`（保护标签） | **保护** | 跳过清理 |
> | `block_keywords`（保护关键词） | **保护** | 跳过清理——**这是保护名单，不是删除名单** |
> | `verified_extra`（强制删除许可 Hash） | **删除许可** | 允许删除（即使没有 MP 整理记录）——**这是删除许可，不是保护名单** |
>
> 记忆口诀：**除了 clean_dirs 和 verified_extra，其余全是"命中即不删"。**

## 安装

1. 将本仓库加入 MoviePilot 插件市场（`PLUGIN_MARKET` 环境变量，多个仓库逗号分隔）
2. 在 WebUI 插件市场搜索「下载目录空间清理」并安装
3. 进入插件配置，调整阈值/目录/标签等参数，保存

## 配置说明

| 配置 | 默认 | 作用 | 说明 |
|------|------|------|------|
| enabled | 关 | - | 启用插件 |
| dry_run | 开 | - | 演练模式，只记录不删除（**首次使用建议先演练**） |
| onlyonce | 关 | - | 立即运行一次（执行后自动复位） |
| cron | `0 */6 * * *` | - | 检查周期 |
| monitor_path | `E:/` | - | 监控盘目录 |
| threshold_free_gb | 300 | 触发 | 可用空间低于该值开始清理（GiB） |
| target_free_gb | 350 | 停止 | 清理到该可用空间即停（GiB，软目标） |
| downloaders | 空=全部 | - | 下载器多选（自动识别 MP 配置） |
| clean_dirs | `E:/Downloads` | **删除范围** | 清理目录白名单，仅子树内任务会被清理 |
| exclude_dirs | 空 | **保护** | 排除目录，命中子树即跳过，优先于清理目录 |
| protect_tags | `保种`/`H&R` | **保护** | 保护标签，命中即不清理 |
| block_keywords | 空 | **保护** | 保护关键词，路径/名称命中即跳过（不是删除名单） |
| min_seeding_days | 15 | 过滤 | 最小做种天数 |
| protect_recent_days | 7 | 过滤 | 完成保护天数，完成不满该天数不清理 |
| min_ratio | 0 | 过滤 | 分享率门槛（0=关） |
| min_size_gb | 0 | 过滤 | 小文件保护（0=关） |
| require_library | 开 | 过滤 | 要求已入库（整理记录或强制删除许可） |
| verified_extra | 空 | **删除许可** | 强制删除许可 Hash：已人工核查入库但无整理记录的种子，命中也允许删除；普通情况留空 |
| delete_files | 开 | 动作 | 同时删除本地文件 |
| delete_history | 开 | 动作 | 同步清理 MP 历史记录 |
| clean_empty_dirs | 关 | 动作 | 空目录回收 |
| tag_then_delete | 关 | 动作 | 两阶段删除 |
| max_delete_per_run | 30 | 动作 | 单轮最多删除任务数 |

## 注意事项

- qBittorrent 删除任务并删文件为**永久删除、不进回收站**，请谨慎开启并先演练
- 「已整理」标签不等于保证入库，删除前以整理记录（status=成功且目标在媒体库路径）为准
- 停止线为软目标：候选不足时可能停在线下
- qB 删除文件为异步落盘，停止线判断时刻的可用空间可能还没算上刚删的文件
- ⚠️ 调高 threshold_free_gb 后请检查 target_free_gb：插件会把它规范化到不低于阈值

## 技术说明

- 插件仅操作下载器与本地磁盘，不访问 115 等网盘
- qB 连接信息全部来自 MoviePilot 下载器配置，插件不存储任何凭据
- V3 SDK：`app.sdk.plugin._PluginBase` / `app.sdk.services.DownloaderHelper` / `app.db.oper.transferhistory`
